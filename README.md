# Personal Financial Planner — Public Tax Rules

Public distribution repository for reviewed, signed tax-rule packages, signed update catalogs, release notes, installation instructions, and public publisher verification material for Sokozi Personal Financial Planner.

No rule-package release is available yet. Packages will be published only after content review and publisher backup verification. This repository does not contain the private planner application source, household data, or private signing credentials.

Tax-rule packages support the documented planning scope; they are not tax-return preparation or filing services.
